# مُنجز أكاديمي

واجهة عربية وخادم Python صغير لعداد الزوار، دون اشتراكات. الهوية وخط Tajawal والشعار محفوظة.

## التشغيل

من مجلد المشروع:

```sh
python3 server.py --host 127.0.0.1 --port 8000
```

## الاختبارات من ملف

افتح «الاختبارات والتصحيح»، ثم اختر TXT (UTF-8 أو UTF-16 مع BOM)، أو DOCX، أو PDF نصياً. تُقرأ الملفات محلياً؛ لا تُرسل إلى API. الحد10 ميغابايت، و200,000 حرف، و150 صفحة PDF. راجع النص المستخرج، واختر1–50 سؤالاً والنوع، ثم راجع الأسئلة والخيارات والمفتاح قبل البدء.

التوليد المحلي ينتج تمارين إكمال من المقاطع بصيغة اختيار من متعدد، أو أسئلة تطابق صياغة النص بصح/خطأ. يعرض المقطع الأصلي، ولا يدعي الاستنتاج أو توليد أسئلة تحليلية بواسطة AI. يلزم عدد كافٍ من الجمل المختلفة؛ لن تكرر الأسئلة لتكملة العدد. ملفات PDF المصورة تحتاج OCR ولا تدعمها هذه النسخة. الموضوع المختصر وحده لا يكفي. النص والملف والاختبار لا يحفظون بعد تحديث الصفحة.

البنوك السابقة محفوظة؛ عند اختيار نوع وعدد يتجاوزان الأسئلة المتاحة تظهر رسالة لتعديل العدد أو رفع مادة. أضيفت مواد تدريبية للأخلاقيات وبولونيا؛ ليست بديلاً عن التعليمات الجامعية الرسمية.

## الحلول وتصدير الأسئلة للأساتذة

في المعاينة تبقى مفاتيح الإجابات والمصادر مخفية. فعّل «إعداد المدرّس» لتحرير الأسئلة والخيارات والمفتاح ومراجعة المصدر. هذا وضع واجهة لإعداد المادة، وليس صلاحية حساب سحابي. أثناء التدريب يظهر الحل والتفسير بعد اختيار الإجابة فقط، وتثبت الإجابة لسلامة الدرجة. الرجوع إلى سؤال مجاب عنه يحتفظ بإجابته؛ إعادة الأسئلة الخاطئة تبدأ محاولة جديدة. الأسئلة المتروكة لا تكشف الحل في التقرير.

يمكن تنزيل Word حقيقي (.docx) بعنوان الاختبار واسم المدرّس. النسخة الافتراضية تتضمن الأسئلة والخيارات دون حلول أو مصادر. في إعداد المدرّس يمكن إضافة مفتاح الإجابات في صفحة مستقلة؛ افصل هذه الصفحة قبل توزيع الأسئلة. الملف قابل للتحرير، بتخطيط A4 واتجاه عربي وخط Tajawal؛ قد يستبدله Word بخط آخر إذا لم يكن Tajawal مثبتاً على الجهاز. التصدير محلي ولا يتطلب خدمة مدفوعة أو رفع المحتوى.

## مساعد اختيار الخدمة والطلبات

يفتح زر «ساعدني في اختيار الخدمة» مساراً من 3 أسئلة، أو4 عند اختيار تنسيق ملف. يربط الاحتياج بالخدمات العشر المعرفة فعلياً، ثم يفتح نموذج الطلب بالخدمة المقترحة. جميع المسارات ونماذج الطلب متاحة دون تسجيل. يمكن طلب أي خدمة من بطاقتها أيضاً، مع بقاء رابط واتساب المباشر.

يمكن تعديل الخدمة والفئة وإضافة اسم اختياري ووصف وموعد مفضل. بعد الإقرار بالنزاهة تظهر معاينة التفاصيل ورابط واتساب إلى الرقم المعتمد9647819934210. الضغط على «تجهيز الطلب» لا يرسل رسالة ولا ينشئ طلباً في قاعدة بيانات؛ الزائر يراجع الرسالة ويرسلها بنفسه من واتساب. تعديل الحقول يبطل المعاينة القديمة. لا تحفظ تفاصيل الطلب تلقائياً بعد تحديث الصفحة.

## عداد الزوار والحساب الاختياري

تظهر أيقونتا الزوار والحساب في الرأس حتى على الهاتف. الحساب الحالي محلي، وFirebase اختياري وغير مفعل؛ لا توجد بوابة حساب تمنع التصفح أو الطلب. نافذة الحساب تتيح «متابعة كزائر».

الخادم يحفظ عدداً تقريبياً للمتصفحات المميزة في SQLite تحت `.local/visitors.sqlite3`، باستخدام رمز عشوائي في ملف تعريف ارتباط HttpOnly / SameSite=Lax صالح90 يوماً. تخزن قاعدة البيانات بصمة الرمز فقط، دون البريد أو الاسم أو عنوان IP. تحديث الصفحة لا يزيد العدد للمتصفح نفسه. مسح ملف تعريف الارتباط أو استعمال متصفح/جهاز آخر يزيده؛ ليس عداد أشخاص أو متصلين الآن ولا يتضمن منعاً شاملاً للروبوتات.

في الاستضافة الثابتة أو عند فتح الملفات مباشرة يظهر «—» إذا كان `/api/visitors` غير متاح؛ لا يُختلق رقم من التخزين المحلي. لتفعيل العداد على الموقع المنشور يلزم تشغيل `server.py` أو توفير API مماثل. عند تشغيله خلف HTTPS استخدم `--secure-cookies`، واحتفظ بقاعدة البيانات على مساحة دائمة (`--db` أو `MUNJIZ_DB_PATH`). ملفات قاعدة البيانات والمسارات الخاصة غير متاحة عبر خادم الويب. لا يرفع هذا العمل الموقع إلى استضافة عامة.

## البيانات المحلية

المراجع وبنود الترقية والملف الشخصي تحفظ على هذا المتصفح فقط. زر حذف الملف المحلي يطلب التأكيد ثم يحذف البيانات المرتبطة من المتصفح أيضاً. صدّر CSV أو انسخ المراجع قبل الحذف. ليست هذه حسابات سحابية ولا يوجد تحقق ملكية البريد. Firebase الاختياري غير مفعّل.

DOI يتصل بـCrossref، وخط Tajawal يُحمّل من Google Fonts. قارئا PDF وDOCX موجودان محلياً داخل vendor ويُحمّلان عند الحاجة فقط.

## التحقق

```sh
node --check app.js
node --check quiz-core.js
node --check quiz-export.js
node --check service-assistant.js
node tests/quiz-core.test.js
node tests/quiz-export.test.js
node tests/service-assistant.test.js
python3 -m unittest discover -s tests -p 'test_server.py'
python3 tests/browser_smoke.py
python3 tests/service_browser.py
```

الاختبار الأخير يحتاج Python Playwright وChromium المثبتين في البيئة، وخادم المشروع على المنفذ8000. ينشئ ملفات اختبار وسياق متصفح مؤقتاً، ويتحقق من الرفع والدقة والحفظ والتقرير والهاتف. لا يرسل ملفات إلى خدمات خارجية.
