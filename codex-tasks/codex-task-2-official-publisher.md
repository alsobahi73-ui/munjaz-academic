# المهمة 2 — الناشر التلقائي للمصادر الرسمية (Official Publisher)
# الصق هذا الملف كاملًا في Codex كـ thread مستقل.

## سياق المشروع (مشترك لكل المهام)
- منصة «مُنجز أكاديمي» / Munjaz Academic — موقع ثابت (HTML+CSS+JS)، عربي RTL.
- المستودع يحتوي: `index.html`، `munjaz-promotion-calculator.html`، `AGENTS.md`.
- قواعد صارمة: لا محتوى مختلق، نسبة المصدر دائمًا، لا تعديل لعناوين الأخبار الرسمية.
- قاعدة أمنية: التوكن يُحفظ كـ GitHub Secret فقط — ممنوع في أي ملف أو سجل.
- لا سيرفر مدفوع أو دائم — GitHub Actions فقط.

## المتطلبات المسبقة (يجهزها المالك)
1. توكن البوت من BotFather → يُحفظ كـ GitHub Secret باسم `TELEGRAM_BOT_TOKEN`.
2. قناة تيليجرام عامة للأخبار والبوت مشرف فيها → معرفها كـ Secret باسم `TELEGRAM_CHANNEL_ID`.
3. المهمة 1 منجزة (ملف `news_queue.json` يُنتَج من المجمّع).

## الهدف
أي خبر `official` جديد يُنشر فورًا ودون تدخل في: (أ) موقع المنصة، (ب) قناة التيليجرام.

## التفاصيل
- اقرأ `news_queue.json`؛ لكل عنصر `official`:
  1. أضفه إلى `news.json` (المصفوفة التي يقرأها الموقع) بالحقول: `title`, `url`, `source`, `date`, `summary`, `category`.
  2. انشره في قناة التيليجرام عبر Bot API بتنسيق عربي ثابت:
     ```
     📰 [العنوان]
     [الملخص بسطر واحد]
     المصدر: [اسم المصدر] | [التاريخ]
     🔗 [الرابط]
     ```
  3. انقل العنصر من الطابور إلى `published.json` مع طابع زمني.
- التوكن من متغير البيئة `TELEGRAM_BOT_TOKEN` ومعرف القناة من `TELEGRAM_CHANNEL_ID` — لا قيم مكوّدة في الكود.
- معالجة الأخطاء: فشل إرسال التيليجرام لا يمنع تحديث الموقع (يُعاد المحاولة في التشغيل التالي)، والعكس.

## معيار القبول
خبر رسمي تجريبي يظهر في `news.json` ويصل القناة بالتنسيق المطلوب خلال دقائق من التشغيل المجدول.
