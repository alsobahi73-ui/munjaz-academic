# المهمة 1 — المجمّع المجدول (Collector)
# الصق هذا الملف كاملًا في Codex كـ thread مستقل.

## سياق المشروع (مشترك لكل المهام)
- منصة «مُنجز أكاديمي» / Munjaz Academic — موقع ثابت (HTML+CSS+JS)، عربي RTL.
- المستودع يحتوي: `index.html` (الصفحة الرئيسية)، `munjaz-promotion-calculator.html` (حاسبة الترقية)، `AGENTS.md` (تعليمات الوكلاء).
- قواعد صارمة: لا محتوى مختلق (لا أخبار وهمية، لا روابط وزارية مزيفة)، نسبة المصدر دائمًا، لا تعديل لعناوين الأخبار الرسمية.
- قاعدة أمنية: التوكن يُحفظ كـ GitHub Secret فقط — ممنوع كتابته في أي ملف أو سجل.
- لا يعتمد على أي سيرفر مدفوع أو دائم — GitHub Actions فقط.

## المتطلبات المسبقة (يجهزها المالك قبل التشغيل)
1. مستودع GitHub للمشروع.
2. قائمة المصادر الرسمية المعتمدة (أدناه).

## الهدف
سكربت يعمل تلقائيًا عبر GitHub Actions، يجمع الأخبار الجديدة من المصادر الرسمية، ويمنع التكرار.

## التفاصيل
- ملف إعداد `sources.yaml`: لكل مصدر (الاسم، الرابط، النوع: رسمي/غير رسمي، الفئة من فئات المنصة السبع).
- المصادر الرسمية المعتمدة:
  - موقع وزارة التعليم العالي والبحث العلمي `mohesr.gov.iq` — قسما «أخبار الوزارة» و«أخبار الجامعات».
  - **جميع الجامعات العراقية الحكومية والأهلية** — ابنِ القائمة الكاملة من دليل الجامعات الرسمي في موقع الوزارة (قسم «دليل الجامعات»)، ثم أضف صفحة الأخبار الرسمية لكل جامعة إلى `sources.yaml`. القائمة شاملة وقابلة للتحديث (سكربت أو خطوات موثقة لإعادة البناء عند استحداث جامعات).
- الجدولة (قابلة للتعديل من `sources.yaml`): الوزارة كل ساعة، الجامعات كل 6 ساعات.
- خطوة أولى إجبارية: افحص كل مصدر بحثًا عن خلاصة RSS/Atom رسمية واستخدمها إن وجدت؛ إن لم توجد نفّذ قراءة مهذبة لصفحة الأخبار (مهلة بين الطلبات، User-Agent معرّف، احترام robots.txt).
- **عزل الأعطال إجباري:** فشل مصدر واحد لا يوقف البقية — يُسجَّل في `runs.log` ويُستكمل الباقي. أي مصدر يفشل 5 تشغيلات متتالية يُعلَّم `needs_attention` في التقرير.
- لكل خبر استخرج: العنوان، رابط الخبر الأصلي، تاريخ النشر، ملخص قصير (1–2 سطر)، اسم المصدر.
- منع التكرار: بصمة hash للرابط + العنوان في `seen.json`؛ المكرر يُتجاهل نهائيًا.
- المخرجات: عناصر جديدة في `news_queue.json` مع حقل `type`: ‏`official` أو `unofficial`.
- سجل `runs.log` واضح: عدد الأخبار الجديدة، أي مصدر فشل ولماذا.

## معيار القبول
تشغيل تجريبي ببيانات وهمية ينتج `news_queue.json` سليمًا، وإعادة التشغيل لا تكرر أي خبر.
