# المهمة 3 — طابور المراجعة للمصادر غير الرسمية + ربط الموقع (Approval Flow + Website Binding)
# الصق هذا الملف كاملًا في Codex كـ thread مستقل.

## سياق المشروع (مشترك لكل المهام)
- منصة «مُنجز أكاديمي» / Munjaz Academic — موقع ثابت (HTML+CSS+JS)، عربي RTL.
- المستودع يحتوي: `index.html`، `munjaz-promotion-calculator.html`، `AGENTS.md`.
- قواعد صارمة: لا محتوى مختلق، نسبة المصدر دائمًا.
- قاعدة أمنية: التوكن والأسرار كمتغيرات بيئة / GitHub Secrets فقط.

## المتطلبات المسبقة (يجهزها المالك)
1. توكن البوت من BotFather (Secret: `TELEGRAM_BOT_TOKEN`).
2. محادثة تيليجرام خاصة للمراجعة والبوت مشرف فيها (معرفها Secret: `TELEGRAM_REVIEW_CHAT_ID`).
3. قناة تيليجرام عامة (Secret: `TELEGRAM_CHANNEL_ID`).
4. المهمة 1 منجزة (`news_queue.json`).

## الهدف
أخبار المصادر غير الرسمية لا تُنشر إلا بموافقة المالك بضغطة واحدة، وربط قسم الأخبار في الموقع بملف `news.json`.

## التفاصيل — جزء أ: الموافقة
- لكل عنصر `unofficial` جديد: أرسل رسالة إلى المحادثة الخاصة للمالك عبر البوت (العنوان + الملخص + المصدر + الرابط) مع زرّين: «✅ انشر» و«❌ تجاهل».
- عند «انشر»: يُنشر الخبر في القناة العامة (بنفس تنسيق المهمة 2) ويُضاف إلى `news.json` ويُنقل إلى `published.json`. عند «تجاهل»: يُنقل إلى `ignored.json` ولا يظهر أبدًا.
- القيد: ممنوع أي سيرفر مدفوع أو دائم — نفّذ الاستقبال عبر Webhook على طبقة مجانية (مثل Cloudflare Workers free tier) أو بديل مجاني موثوق.
- بديل احتياطي إجباري: إن تعذّر الـ Webhook، وثّق طريقة يدوية بسيطة (إعادة إرسال الخبر المعتمد) ولا تترك الميزة معطلة بصمت.

## التفاصيل — جزء ب: ربط الموقع
- عدّل `index.html` لتقرأ الأخبار من `news.json` عبر `fetch` عند التحميل، مع fallback للمصفوفة المضمنة حاليًا إن فشل الجلب.
- حافظ على السلوك الحالي حرفيًا: الشريط المتحرك يختفي تلقائيًا عند فراغ الأخبار، والتصميم والألوان والـ RTL كما هي.
- الهوية مجمّدة: الاسم «مُنجز أكاديمي» / Munjaz Academic (ممنوع تهجئة Munjiz)، الألوان teal `#0E6B66` وكهرماني `#B97A12`، لا إيموجي في الواجهة، لا أزرار ذهبية.
- لا أخبار تجريبية «تجريبي:» في أي ملف يُرفع.

## معيار القبول
خبر غير رسمي تجريبي يصل الخاص بأزراره، والموافقة تنشره في القناة والموقع، والتجاهل يخفيه نهائيًا.
