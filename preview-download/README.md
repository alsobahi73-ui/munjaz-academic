# معاينة مُنجز أكاديمي

[تنزيل حزمة المعاينة ZIP](https://github.com/alsobahi73-ui/munjiz-academic/raw/refs/heads/codex/platform-preview-review/preview-download/munjiz-preview.zip)

1. نزّل الحزمة ثم فك الضغط عنها.
2. افتح `index.html` باستخدام Google Chrome أو Microsoft Edge.
3. إذا ظهر الملف كنص، انقر عليه بالزر الأيمن واختر «فتح باستخدام» المتصفح.

الحزمة تضم ملف المعاينة الموحد وتعليمات الفتح وتقرير المراجعة العربي.

الخطوط والتنسيق والبرامج مضمنة داخل ملف HTML. البحث عبر Crossref والتواصل عبر واتساب يحتاجان إلى اتصال بالإنترنت. عداد الزوار يحتاج إلى الخادم ولا يعطي عدداً حقيقياً عند فتح الملف محلياً. قسم التعيينات لا يحتوي على إعلانات حتى توثيقها من مصادرها الرسمية.

هذه نسخة للمراجعة، وليست نشراً للموقع أو دمجاً في الفرع الرئيسي.
