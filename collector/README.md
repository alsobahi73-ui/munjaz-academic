# المجمّع — المهمة 1

هذا المجمّع يجمع فقط؛ لا ينشر ولا يحتاج توكن تيليجرام. بيانات الاختبار محلية ولا تدخل الموقع أو طابور الإنتاج.

## التشغيل

Python 3.12 أو أحدث:

```sh
python -m venv /tmp/munjaz-collector-venv
/tmp/munjaz-collector-venv/bin/pip install -r collector/requirements.txt
/tmp/munjaz-collector-venv/bin/python -m unittest discover -s collector/tests -v
/tmp/munjaz-collector-venv/bin/python -m collector.collect --sources sources.yaml --output .
```

GitHub Actions يعمل كل ساعة؛ لكل مصدر موعده في `sources.yaml` (الوزارة ساعة، الجامعات ست ساعات). جداول GitHub تقريبية وقد تتأخر. يحتفظ `collector_state.json` بالموعد وآخر نجاح وعدد الإخفاقات؛ بعد خمسة إخفاقات متتالية يظهر `needs_attention` في التقرير. يحتاج المستودع السماح للـ Actions بالكتابة إلى main. جميع مهام تعديل الطابور اللاحقة يجب أن تستخدم مجموعة التزامن `news-publication-state` وتقرأ أحدث main قبل تعديل الحالة. لا تحذف `seen.json` بعد النشر.

## الحالة الحالية والعائق

`https://mohesr.gov.iq/` هو النطاق الوحيد المعتمد المتاح في التعليمات. طلب الشبكة الفعلي رُفض بواسطة وكيل البيئة (403 CONNECT). لذلك `sources.yaml` لا يحتوي روابط أقسام أو جامعات مخمّنة، وحالته `pending_network_access`. التشغيل الإنتاجي يرفض هذه الحالة بوضوح. قائمة الجامعات الكاملة والتحقق المباشر من المصادر لم ينجزا بعد. الفئات السبع غير معرّفة في هذا checkout؛ `general` مؤقتة ويجب مطابقة معرفات الفئات مع عقد الناشر قبل التفعيل.

## إعادة بناء القائمة من الدليل الرسمي (عند فتح الشبكة)

1. افتح الصفحة الرئيسية للوزارة واتبع رابط «دليل الجامعات» الفعلي؛ احتفظ بعنوان الدليل وتاريخ المراجعة وعدد المؤسسات الحكومية والأهلية كما يظهر رسميًا. لا تعتمد قائمة طرف ثالث.
2. راجع جميع صفحات الدليل والجداول/ملفات الدليل الرسمية المرتبطة به. أضف كل مؤسسة وروابطها المنقولة من الدليل إلى سجل مراجعة محلي، مع تمييز الحكومية والأهلية. قارن المجموع بعدد الدليل؛ لا تعلن اكتمال القائمة إذا كان رابط أو مؤسسة مفقودًا.
3. اتبع روابط «أخبار الوزارة» و«أخبار الجامعات» من الوزارة نفسها. افتح الموقع الرسمي لكل مؤسسة من الدليل واتبع رابط صفحة الأخبار الحقيقي. لا تستنتج روابط /news أو /feed من اسم الجامعة.
4. افحص RSS/Atom المعلنة عبر `link rel=alternate` وروابط RSS المرئية. المجمّع يفحص الإعلانات آليًا عند كل تشغيل ويعطيها الأولوية. أضف `feed_url` للخلاصات المرتبطة رسميًا التي لا تظهر ضمن إعلان الرأس. خلاصة بنطاق مختلف تحتاج مراجعة ودعمًا منفصلًا، ولا تُقبل تلقائيًا.
5. إذا لم توجد خلاصة، سجّل محددات CSS بعد فحص عناصر الأخبار الفعلية (`item`, `title`, `link`, `date`, `summary`). افحص robots.txt أولًا. لا تخمّن تاريخ نشر مفقودًا. المواقع التي لا يمكن استخراج تاريخها أو تمنع الجمع تُسجّل كعائق، لا تُسقط بصمت.
6. أضف كل مصدر إلى `sources.yaml` وفق المثال أدناه؛ احتفظ بالمصادر المعطلة مع السبب إذا لم تسمح بالقراءة، ثم راجع التغطية الكاملة وأسماء الفئات السبع. حدّث سجل المراجعة وغيّر `directory_status` إلى `verified` فقط بعد اكتمالها.
7. شغّل أولًا بمجلد إخراج مؤقت و`--force`، وافحص نسبة المصدر والعناوين الأصلية والتواريخ والتقرير. أعد التشغيل للتحقق من عدم التكرار. كرر التدقيق دوريًا وعند استحداث مؤسسة؛ حافظ على `id` ثابت وعلى حالة منع التكرار.

بنية المصدر (قيم توضيحية، ليست مصدرًا إنتاجيًا):

```yaml
id: unique-stable-id
name: الاسم الرسمي
url: عنوان صفحة الأخبار المتحقق منه
type: official  # أو unofficial: يضاف للطابور ولا ينشر تلقائيًا
tier: university  # ministry للوزارة
category: معرف فئة معتمد
enabled: true
# feed_url: الرابط المعلن رسميًا عند الحاجة
selectors:
  item: article
  title: h2
  link: h2 a
  date: time
  summary: p
```

الإخراج: `news_queue.json` مصفوفة حقول `id,title,url,date,summary,source,source_id,type,category,collected_at`، و`seen.json` بصمات SHA-256 للرابط + سطر جديد + العنوان. يُحفظ الطابور قبل البصمات وتتم تسويته عند إعادة التشغيل. ملفات JSON تستبدل ذريًا؛ يجب عدم تشغيل كاتبين للحالة في الوقت نفسه. السجل `runs.log` سطر JSON لكل مصدر وملخص تشغيل. لا تُخترع تواريخ أو ملخصات؛ الملخص فارغ إذا لم يوفره المصدر. القراءة بمهلة 25 ثانية، حد حجم 4 MB، انتظار لا يقل عن ثانيتين ومراعاة crawl-delay/request-rate. فشل robots.txt يمنع القراءة ما عدا 404/410، والتحويلات تتطلب اعتماد الرابط النهائي بدل تجاوز سياسة الموقع.

## حقل date_page_selector (قوائم بلا تواريخ)

بعض المواقع الرسمية (مثل موقع الوزارة mohesr.gov.iq) تعرض قائمة الأخبار **دون تاريخ النشر**؛ التاريخ موجود فقط في صفحة الخبر نفسه. لهذه الحالة أضف للمصدر:

```yaml
selectors:
  item: div.side-news-grid li
  title: div.title
  link: a._link
  # date: لا يوجد في القائمة — يُترك فارغًا
date_page_selector: img.post-img + div.post-views div.date
```

السلوك: الجامع يجمع القائمة أولًا، ثم يجلب صفحة كل خبر **جديد** فقط ويستخرج تاريخه بالمحدد. الخبر الذي لا يُعثر له على تاريخ في صفحته **يُسقط ولا يُخمَّن له تاريخ** (يُسجَّل في runs.log). لا يُستخدم هذا الحقل إلا عند غياب التاريخ في القائمة.
