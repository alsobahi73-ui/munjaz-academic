# المراجعة الوظيفية — 15 أكتوبر 2026

هذه مراجعة محلية للملفات والصفحات والمنطق والإعدادات. لم تُنشر التعديلات ولم تُرسل رسائل أو طلبات حقيقية للمستخدمين. تغييرات تنسيق الأخبار الموجودة قبل المراجعة محفوظة ضمن النسخة المفحوصة.

## ما أُصلح

- إتاحة صفحتي الباحثين عن عمل وحاسبة الترقية المستقلة عبر خادم Node، مع استمرار منع الوصول إلى ملفات المصدر والإعدادات الخاصة.
- تصحيح حدود مدخلات حاسبة حجم العينة: قبول هامش 50% ورفض مجتمع سالب أو كسري. منع متوسطات درجات خارج الحد الأعلى أو وحدات سالبة، وعدم عرض تقدير مضلل لمقياس GPA غير محدد.
- عدم تجاهل نوع أسئلة الاختبار: اختيار متعدد أو صح/خطأ أو مختلط. عرض الموضوعات غير المطبقة والنص المخصص بحالة «قيد التجهيز»، مع الإعلان عن العدد المتاح الفعلي.
- حفظ الكسور العشرية في حاسبة الترقية المستقلة، ومعالجة البيانات المحلية غير الصالحة، ومنع تفسير اسم البند كـHTML. تحسين صف المدخلات على الجوال.
- إظهار زر عكس الوحدات على الجوال ومعالجة رفض الحافظة دون إعلان نجاح النسخ.
- تصحيح نطاق تنسيق الطباعة بحيث لا تُخفى صفحات الموقع عند الطباعة خارج نافذة الترقية. اختبار ظهور نتيجة الترقية في وضع الطباعة وتنزيل CSV.
- تحليل تواريخ الأخبار اليومية بصيغة يوم/شهر/سنة قبل ترتيبها، مع توحيد عرض التاريخ واتجاه العناوين.
- منع حلقة لا تنتهي عند تفعيل تقليل الحركة على شريط قصير؛ إعادة ضبط التكرار عند تغيير تفضيل الحركة.
- حماية Webhook البوت عند غياب السر، وفحص قبول تيليجرام قبل إرسال تأكيد للمستخدم، وعرض النص دون تفسير HTML، وتقسيم الرسائل الطويلة. إعادة استخدام المعالج وتذكر الأجزاء والتحديثات المؤكدة ضمن نسخة العامل.
- توافق صياغة خدمات الرسائل والبحوث والمجلات مع الإرشاد والدعم الأكاديمي، دون وعد بالكتابة نيابة عن المستخدم.
- جعل `npm test` يشغّل جميع مجموعات اختبارات Node الحالية، وتصحيح اسم الحزمة وتحديث التوثيق القديم.

## إعادة التنفيذ

```sh
npm test
/workspace/.munjaz-venv/bin/python -m unittest discover -s collector/tests -v
npm start
```

من طرفية أخرى، مع وحدة Playwright ومتصفح Chromium المتاحين في بيئة الفحص:

```sh
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright AUDIT_SITE_URL=http://localhost:3000 node scripts/browser-audit.cjs
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright AUDIT_SITE_URL=http://localhost:3000 node scripts/browser-news-audit.cjs
```

يمكن تعيين `PLAYWRIGHT_MODULE` لمسار التثبيت المحلي و`CHROMIUM_EXECUTABLE` لمسار المتصفح. لا تُضاف مكتبات للواجهة، ولا تُخزن أسرار في هذه الأوامر.

## حدود لا تزال قائمة

- لا تتوفر أسرار تيليجرام وCloudflare في هذه الجلسة. لم يُنفَّذ نشر أو إرسال فعلي أو تحقق من إعدادات الحساب الخارجي. تشغيل النماذج الحي يعتمد على إعدادات العامل وأصل الموقع ومحادثة المالك الصحيحة.
- صفحة الباحثين عن عمل للاطلاع فقط: الإرسال والتخزين وفلترة سجلات حقيقية غير مفعلة. تحتاج ربطًا فعليًا وصلاحيات واضحة؛ لا تعرض سجلات وهمية.
- الموضوعان الإضافيان للاختبار والتوليد من نص مخصص غير مطبقين. الملف الشخصي محلي ما لم تُضبط Firebase؛ لا يوجد ادعاء بحساب سحابي.
- فحص كل مصدر إخباري خارجي ونتائج الجدولة والقناة الحقيقية لم يُنفَّذ. كانت الملفات تحتوي 115 مصدرًا، منها 73 مفعّلًا، و953 خبرًا؛ هذه لقطة وليست ضمانًا لاتصالها أو اكتمال قائمة المؤسسات.
- منع تكرار رسائل البوت وطلبات الخدمات يعتمد على ذاكرة نسخة العامل. لا يضمن منع التكرار عند انقطاع غير مؤكد أو إعادة التشغيل أو عبر مناطق متعددة دون تخزين دائم مشترك.
- المراجعة لا تدّعي خلو المشروع من كل خطأ محتمل؛ تغطي المسارات والفحوص المذكورة مع فصل ما لم يُختبر حيًا.
